X Logo Download (SVG, PDF, EPS, AI, PNG)

Download the X logo vector in SVG, PDF, EPS, AI, and PNG formats for free — each file available as a separate download. This is the minimalist “X” mark that replaced Twitter’s blue bird logo in July 2023, now used across the platform’s app icon, website, and branding.

Twitter’s rebrand to X was announced by owner Elon Musk in July 2023, replacing the bird logo the platform had used since 2012 with a stark, monochrome “X” symbol. The design is a monoline, geometric mark loosely based on the Unicode multiplication sign, rendered in solid black (#000000) for maximum contrast and versatility across app icons, dark and light interfaces, and print. Unlike the bird, which carried decades of brand recognition, the X mark was designed to work as an abstract, scalable glyph that reads clearly at any size — from a favicon to a billboard.

The platform’s ownership structure has continued to evolve since the rebrand. In March 2025, X Corp merged with Musk’s AI company xAI in an all-stock deal, combining the social platform with the Grok chatbot under a single holding company. In February 2026, SpaceX acquired xAI in what was reported as the largest private merger in history, folding X into an even larger corporate structure alongside SpaceX’s aerospace and satellite business. The X logo itself has remained unchanged through these ownership changes.

Each vector format (SVG, EPS, AI, PDF) can be downloaded individually depending on which design software you’re using, so you only grab the file type you actually need. The transparent PNG is the fastest option for documents, presentations, and mockups where a vector file isn’t required.
